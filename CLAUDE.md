Project-level instructions for Claude Code sessions on this repo. Read this before making changes.

## What this site is

alpcakin.com is being converted from a pure economics blog into **Alp Çakın's developer portfolio**, with the economics/macro blog kept as a secondary "Blog" section rather than the homepage. The goal: convince both recruiters (full-time hiring) and non-technical prospects (freelance/contract clients) that Alp builds real products. Full context and every locked-in decision is in:

- [`docs/portfolio-redesign-plan.md`](./docs/portfolio-redesign-plan.md) — the implementation plan.
- [`docs/portfolio-redesign-qa.md`](./docs/portfolio-redesign-qa.md) — the full requirements interview + researched facts (CV, bayerpos.com) it's based on.

Read both before touching site structure, positioning copy, or the project list — they contain decisions that aren't obvious from the code alone.

## Hard constraints

- **Dark-only terminal theme.** No theme toggle, no light variant. As of 2026-10-16 the site is a tmux/vim-style terminal UI (Claude Design canvas "alpcakin.com — Terminal Redesign", direction **B · tmux**, explicitly chosen by Alp — supersedes the 2026-07-20 light "warm paper" rule that used to live here). Palette lives in `src/styles/global.css` `:root`: `--background:#0a0e0b` (ground), `--foreground:#d2e3d5`, `--accent:#7ee787` (phosphor green), `--muted:#121a14` (status bar), `--border:#26352a` / `--border-strong:#3a4d3f`, `--muted-foreground:#7f9684`. Don't reintroduce the paper/ink palette, the old near-black/gold one, or a theme switch.
- **No Turkish site content.** English only, no auto-translate/geolocation-based language switching. (This doesn't apply to the Veresiye legal pages above, which are Turkish by requirement.)

## Design system

One typeface: **IBM Plex Mono** (`var(--font-mono)`, loaded through Astro's font pipeline in `astro.config.ts` `fonts:` with `latin-ext` for Turkish/Hungarian characters). Long-form prose reads `--font-prose` (= mono today) so it can be switched in one place. Tokens and shared utility classes (`.shell`, `.row`, `.fill/.side`, `.lk`, `.btn`, `.cursor`, and `.list-shell/.list-head/.list-title/.list-intro/.list-more` for the archive and tag pages) are in `src/styles/global.css`; blog markdown styling is `.prose` in `src/styles/typography.css` (markdown markers like `##`, `-`, `>` are drawn as generated content).

Building blocks — reuse these instead of inventing new idioms:

- `components/tui/Pane.astro` — bordered pane with its title on the top border. Panes with an `id` join focus tracking: the pane filling most of the viewport gets the accent border, and on the homepage the matching tmux window in the top bar gets `*`. Clicking a window pins focus on its pane and flashes the border (`data-flash`), because the homepage is too short to scroll to every pane — without that a click looks like it did nothing. The pin is released by wheel/touch/scroll keys, or once the pane has been on screen and left.
- `components/tui/Prompt.astro` (`$ cmd` line), `components/ShellPath.astro` (breadcrumb as `alp@pécs:~/posts$ cat x.md`).
- `components/Header.astro` (tmux window bar, windows defined in `WINDOWS` in `src/constants.ts`), `components/StatusBar.astro` (vim status line: mode, path, hint, Top/NN%/Bot, `crt` scanline toggle). Both are rendered by `layouts/Layout.astro`, so pages only render `<main class="shell">`.
- `components/work/WorkPane.astro` + `ProjectMedia.astro` — homepage project tabs (WAI-ARIA tabs, deep links `/#work-<slug>`), preview well with `video` / `gallery` / `flow` media. **Project content lives in `src/data/projects.ts`**; role, tagline, status line (shared with the site OG image) and the short experience log in `src/data/profile.ts`.
- `components/PostList.astro` (dated post listing, `compact` / `full`), `components/Lightbox.astro` (any `a[data-zoom]` opens in a `<dialog>`).
- `src/utils/rehype/figures.js` turns stand-alone markdown images into numbered `fig.NN` figure windows that zoom into the lightbox.
- All client behaviour that spans pages (clock, pane focus, scroll position, CRT, lightbox) is in `src/scripts/terminal.ts`; per-page scripts re-run on `astro:page-load` and clean up with an `AbortController` (ClientRouter is on).

Motion is minimal and hand-rolled (no animation libraries): blinking cursor, border-colour focus, the lore recording. `prefers-reduced-motion` stops the blink and the recording's autoplay (a play/pause control is always present) — keep that when adding motion.

## Issues encountered → how solved

- **odesh legal/app-link pages retired from this site (2026-09-22).** `aydinlatma-metni.html`, `kullanim-kosullari.html`, `veri-silme.html`, `public/.well-known/apple-app-site-association`, `public/.well-known/assetlinks.json`, and the 404 page's `/join*` fallback have all been deleted. odesh now has its own marketing site (`odesh-web` repo, deployed at odesh.app) that hosts the legal texts at `/yasal/*` and its own `.well-known` files with the same appID/package/fingerprint. App Store Connect and Play Console were repointed to odesh.app the same day. Deleting the `.well-known` files here does mean deep links break for users still on an app build older than the one with the updated `associatedDomains`/`intentFilters` (confirmed and accepted as a tradeoff, not an oversight) — see `odesh/docs/TODO_production.md` §7 and `odesh/constants/legal.ts` for the migration record. Do not resurrect these pages from git history without checking odesh-web is still the live source of truth.

- **Removing `@custom-variant dark` broke several `dark:` Tailwind usages.** Historical: the old `dark:` utilities were merged into unprefixed values. Since the 2026-10-16 rewrite no component uses Tailwind theme variants at all and `data-theme` is no longer set on `<html>`; Shiki's dark token variables are applied unconditionally in `typography.css`.
- **Site search (Pagefind) was removed entirely (2026-07-20).** Alp decided the nav search button/⌘K modal, the dedicated `/search` page, and the inline search box on the blog archive weren't worth keeping. Removed: `src/components/SearchModal.astro`, `src/pages/search.astro`, the search triggers in `Header.astro`/`MobileMenu.astro`, the inline Pagefind box + init script in `src/pages/posts/[...page].astro`, `data-pagefind-body`/`data-pagefind-ignore` attributes in `PostDetails.astro`, the `.premium-search` CSS block, the `pagefind --site dist && cp -r dist/pagefind public/` build step, and the `pagefind`/`@pagefind/default-ui` dependencies. If search is ever wanted again, it'll need to be re-added from scratch (not just un-commented) — treat any future request for site search as new work, not a revert.
- **The site pivoted from dark to light mid-redesign (2026-07-20).** The portfolio rebuild in `docs/portfolio-redesign-plan.md` was implemented first in the original dark/gold direction; Alp then supplied a Claude Design handoff bundle (`Alp Cakin.dc.html`, a "warm paper" editorial prototype: Instrument Serif + Space Grotesk + Space Mono, electric-blue accent, marquee ticker, numbered hover-to-expand Work accordion, live Pécs clock in the nav) and asked for it to be applied site-wide, explicitly overriding the older dark-only constraint. Local font files for the old Wotfard/Cartograph CF fonts were removed (`src/assets/fonts/`) since nothing references them anymore; `ProjectCard.astro` was deleted in favor of the inline accordion markup in `index.astro`. `docs/portfolio-redesign-plan.md`'s content/structure decisions (which 4 projects, About copy, tech list) still hold — only its "dark, minimal, premium" visual-direction bullets are stale now.
- **The app formerly called "Veresiye" is now "odesh" everywhere, including the legal pages (2026-08-19).** The rebrand was completed in the `veresiye` repo on 2026-08-14 (bundle ID `com.odesh.app`, App Store Connect listing "odesh"); this site's legal/compliance pages (`aydinlatma-metni.html`, `kullanim-kosullari.html`, `veri-silme.html`) still said "Veresiye" and age 18+ until 2026-08-19, which had drifted out of sync with the App Store's declared 16+ age rating and "odesh" listing name — both were updated to match. The portfolio's Work section refers to the same app as **odesh**, described functionally as a shared-debt/expense tracking app (do not name-drop "Splitwise" in on-site copy, just describe the function).
- **Legal pages synced to odesh legal texts v1.1 (2026-09-10).** The three odesh pages are now generated from `veresiye/docs/legal/aydinlatma-metni.md`, `kullanim-kosullari.md` and `veresiye/docs/web/veri-silme.html`; the `Versiyon` in the page meta line must equal `TERMS_VERSION`/`PRIVACY_VERSION` in `veresiye/constants/legal.ts` (the app records that number as the accepted consent version). When odesh bumps the texts, regenerate these pages from the markdown rather than hand-editing paragraphs.
- **Terminal redesign (2026-10-16).** Alp felt the paper/serif site read as "a blog, not an engineer's site" and asked for a hacker/low-level look that stays readable. Four directions were explored in a Claude Design canvas (A man page, B tmux TUI, C objdump memory map, D chip datasheet); Alp picked **B** and asked for room for screenshots/GIFs, which became the full-width preview well in the work pane. Implemented site-wide including the blog: every old component (Card, Breadcrumb, BackButton, BackToTopButton, MobileMenu, Footer, Socials, LinkButton, Datetime, EditPost, `layouts/Main.astro`), the icon SVGs, the Sriracha/Cascadia font files, `src/env.d.ts` (theme typings) and the `showBackButton`/`editPost` config fields were deleted. The lore demo is `lore/docs/demo.gif` converted to `public/media/lore/demo.{webm,mp4}` + `poster.webp` (ffmpeg; 405 KB GIF → 89 KB WebM) — re-export from the lore repo's `docs/demo.tape` when the CLI changes. The profile photo moved from `public/images/` to `src/assets/images/` so Astro optimises it. OG images (`src/utils/og-templates/`) share a terminal frame (`frame.js`) and use IBM Plex Mono. `@tailwindcss/typography` is no longer used by any CSS but is still listed in `package.json` (pnpm isn't installed locally to update the lockfile) — safe to remove with `pnpm remove @tailwindcss/typography`.
